## HIGH Priority

### Detection Quality

- [x] **go/types integration (`--type-aware` mode)** — IMPLEMENTED. Uses `golang.org/x/tools/go/packages` to type-check Go files and encodes each local variable's static type into the identifier hash. Eliminates the `same-method-name-different-receiver-type` false positive class (e.g., `a.String()` where `a` is `time.Time` vs `*big.Int`). Opt-in via `--type-aware` flag (10-100x slower than parsing alone). Falls back gracefully if type checking fails. See `syntax/golang/typeinfo.go` and `cmd/type_aware.go`.
- [ ] **`//art-dupl:accept` inline directive** — Suppress accepted clone groups via inline comments in source code. Enables CI gating without baseline file management. ~150-300 LOC. Top feature request from feedback sessions (httputil, cyberdom, go-auto-upgrade).
- [ ] **Generated `_templ.go` auto-exclusion** — Currently filtered by `.gitignore` (fragile in CI). Should detect `// Code generated by templ - DO NOT EDIT.` header automatically, same as sqlc/protobuf/mockgen detection. Feedback: DiscordSync (67% of groups were in a gitignored generated file).
- [ ] **`.gitignore` honoring during file enumeration** — Skip gitignored files by default with `--include-ignored` escape hatch. Prevents noise from generated/vendored output in CI runs.

### Code Quality

- [ ] **JSON tag convention unification** — Split-brain: `domain`/`pkg/artdupl` use `snake_case`, `baseline`/`cache`/`cmd/version` use `camelCase`. `tagliatelle` linter disabled to hide this. Needs a project-wide decision (ADR candidate) + migration.
- [ ] **SDK_DESIGN.md disposition** — Type names are wrong (`StartLine` vs `LineStart`, field drift). Either rewrite to match current `pkg/artdupl/types.go` or delete it.

### Testing

- [ ] **Unit tests for `cmd/progress.go`** — Forwarding logic, suppression (`--quiet`, `ARTDUPL_NO_PROGRESS=1`), and final count reporting are untested.
- [ ] **Progress output in hash-only mode** — `cmd/progress.go` wraps the file channel for suffix-tree analysis but is NOT wired into `executeHashOnlyAnalysis` (`cmd/run_hash.go`). Gap in feature coverage.

### Architecture

- [x] **Clone type consolidation** — ~~7+ parallel Clone types~~ RESOLVED: `domain.CloneRef` is now embedded in ALL clone-bearing types (`JSONClone`, `CloneOccurrenceView`, `CloneWithContent`, `FileInfo`, `simpleJSONClone`).
