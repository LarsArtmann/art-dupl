How It Works

From Source to Clones in Six Steps

A concurrent pipeline transforms your Go source into actionable clone detection results.

01
Source Files
Scan Go and Templ files from your project paths
02
AST Parse
Parse into abstract syntax trees with concurrent workers
03
Transform
Serialize AST to language-agnostic token sequences
04
Suffix Tree
Build compressed suffix tree for O(n) duplicate search
05
Detect
Find repeating patterns above the token threshold
06
Output
Format as text, HTML, JSON, SARIF, CSV, plumbing, or simple-json

Integration

Built for Your Pipeline

From pre-commit hooks to GitHub Actions. First-class CI/CD support.

Pre-commit Hook

# .pre-commit-config.yaml
repos:
  - repo: local
    hooks:
      - id: art-dupl
        name: art-dupl
        entry: art-dupl --plumbing -t 30
        language: system
        types: [go]

4 hook modes: basic, strict, semantic, and filtered. Catches duplicates before they reach main.

GitHub Actions

# Fail build if too many duplicates
- name: Check duplicates
  run: |
    go install github.com/LarsArtmann/art-dupl/cmd/art-dupl@latest
    TOTAL=$(art-dupl --json . | jq '.summary.total_clones')
    test "$TOTAL" -lt 100

# SARIF upload for GitHub Security
- run: art-dupl --sarif -o results.sarif .
- uses: github/codeql-action/upload-sarif@v3

JSON output for custom thresholds, SARIF for GitHub Advanced Security integration.
