Activate the MethodDetector seam

Strong in-process
detection/detector.go · detection/multidetector.go

Before — Shallow

Interface surface ≈ Implementation
MethodDetector (unused)
MultiDetector: 4 hard-coded branches

After — Deep

Interface surface ≪ Implementation
[]MethodDetector
MultiDetector dispatches in a loop

Problem: MethodDetector interface exists but is never used for dispatch. MultiDetector hard-codes each detector.

Solution: MultiDetector holds []MethodDetector, dispatches in a loop, removes all hard-coded constructors.

  • • Locality: all detector dispatch concentrates in one module
  • • Leverage: one interface, N adapters, zero MultiDetector edits
  • • Interface shrinks; implementation absorbs the branches
