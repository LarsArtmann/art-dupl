### Root Cause Analysis: Why Connect Files Slipped Through

**Symptom:** `art-dupl -t 40 .` on typespec-eventsourcing reported 2 clone groups in generated ConnectRPC code.

**Root cause chain:**

1. `main.connect.go` has `// Code generated by protoc-gen-connect-go. DO NOT EDIT.` on line 8 — standard Go convention
2. `gogenfilter.FilterProtobuf` requires `.pb.go` or `_grpc.pb.go` suffix — `.connect.go` doesn't match
3. `gogenfilter.FilterGeneric` matches ANY `// Code generated by` comment — but **was never wired** in `setupFilter()`
4. This was a **known, documented TODO** in 4+ status/planning docs (2026-04-04, 2026-04-05, 2026-04-15, 2026-05-06) — never executed

**Fix:** Added `FilterGeneric` as 6th filter option with `--include-generic` override (default: filtered).

**Lesson:** When gogenfilter adds new detectors, art-dupl must wire them. Consider using `FilterAll` by default with per-detector opt-out (currently not supported by gogenfilter API — would need `WithExclude(detector)` or similar).
