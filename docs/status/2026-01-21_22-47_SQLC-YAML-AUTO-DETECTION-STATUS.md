### 4. yaml Parsing Implementation (DONE)
**File:** `pkg/filter/sqlc_yaml.go` (NEW FILE)

**Implemented functions:**

#### `FindSQLCConfigs(paths []string) (map[string]string, error)`
- Walks provided paths looking for `sqlc.yaml` or `sqlc.yml` files
- Skips hidden directories and common non-source dirs (.git, node_modules, vendor)
- Returns map of `configPath -> projectRoot`
- Supports both `.yaml` and `.yml` extensions

#### `ParseSQLCConfig(configPath string) (*SQLCConfig, error)`
- Reads and parses sqlc.yaml file using `gopkg.in/yaml.v3`
- Supports sqlc.yaml version 2 format
- Parses structure: `version`, `sql[].engine`, `sql[].gen.go.package`, `sql[].gen.go.out`
- Returns structured `SQLCConfig` object

**Data structures:**
```go
type SQLCConfig struct {
    Version string       `yaml:"version"`
    SQL     []SQLCEngine `yaml:"sql"`
}

type SQLCEngine struct {
    Schema string       `yaml:"schema"`
    Engine string       `yaml:"engine"`
    Gen    SQLCGenConfig `yaml:"gen"`
}

type SQLCGenConfig struct {
    Go SQLCGoConfig `yaml:"go"`
}

type SQLCGoConfig struct {
    Package string `yaml:"package"`
    Out     string `yaml:"out"`
}
```

#### `GetSQLOutputDirs(paths []string) ([]string, error)`
- Finds all sqlc.yaml files in provided paths
- Parses each config to extract output directories
- Constructs absolute paths relative to project root
- Returns list of output directories to filter
- Logs warnings for parse errors but continues processing

**Dependency added:**
```go
import "gopkg.in/yaml.v3"
```
