## How It Works (Existing Implementation)

### FindSQLCConfigs Walks All Subdirectories

**File:** `pkg/filter/sqlc_yaml.go:41-71`

```go
func FindSQLCConfigs(paths []string) (map[string]string, error) {
    configs := make(map[string]string)

    for _, path := range paths {
        // Walk recursively through ALL subdirectories
        err := filepath.Walk(path, func(filePath string, info os.FileInfo, err error) error {
            // ... walks entire tree recursively
            filename := filepath.Base(filePath)
            if filename == "sqlc.yaml" || filename == "sqlc.yml" {
                configs[filePath] = filepath.Dir(filePath)
            }
            return nil
        })
    }

    return configs, nil
}
```

**Key Point:** `filepath.Walk()` recursively traverses ALL directories in the provided path tree.

## Why It Works

### filepath.Walk() Behavior

The standard library `filepath.Walk()` function:

- **Recursively walks** through the file tree rooted at root
- **Visits every file and directory** in the tree
- **Does not stop at first level** - continues through all subdirectories

**From Go Documentation:**

> Walk walks the file tree rooted at root, calling fn for each file or directory in the tree, including root.

This means:

```
Walk(".") will visit:
  ./
  ./db/
  ./db/file1.go
  ./db/subdir/
  ./db/subdir/file2.go
  ./file3.go
```

### Implementation Leverages This

Our implementation at `pkg/filter/sqlc_yaml.go:46`:

```go
err := filepath.Walk(path, func(filePath string, info os.FileInfo, err error) error {

    filename := filepath.Base(filePath)
    if filename == "sqlc.yaml" || filename == "sqlc.yml" {
        configs[filePath] = filepath.Dir(filePath)
    }
    return nil
})
```

**Key Point:** The callback is invoked for files at ANY depth in the directory tree.

## Technical Details

### filepath.Walk() Implementation

**Location:** `pkg/filter/sqlc_yaml.go:46`

```go
err := filepath.Walk(path, func(filePath string, info os.FileInfo, err error) error {
    if err != nil {
        return err
    }

    // This callback is invoked for EVERY file in the tree
    // Including files at any depth (./, ./db/, ./db/sub/, etc.)
    if info.IsDir() {
        name := info.Name()
        if strings.HasPrefix(name, ".") || name == "node_modules" || name == "vendor" {
            return filepath.SkipDir
        }
        return nil
    }

    // Check for sqlc.yaml or sqlc.yml in ANY directory
    filename := filepath.Base(filePath)
    if filename == "sqlc.yaml" || filename == "sqlc.yml" {
        configs[filePath] = filepath.Dir(filePath)
    }

    return nil
})
```

**Key Behaviors:**

1. **Recursive traversal** - Visits files at any depth
2. **Callback per file** - Called for every file/directory
3. **Depth-first or breadth-first** - Not specified by Go, but consistent
4. **SkipDir support** - Can skip hidden/vendor directories

### Why This Handles Nested Configs

When you run `art-dupl .`:

1. Walk starts at `.`
2. Visits `.` (current directory)
3. Visits `./db/` (subdirectory)
4. Visits `./db/sqlc.yaml` ← FOUND!
5. Visits `./db/models.go`
6. Visits `./main.go`
7. Continues to all other subdirectories

The `sqlc.yaml` in `./db/` is discovered and included in the results.
