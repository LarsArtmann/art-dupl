## Headline Finding

**The repo is already broken against Go 1.27, today.** `go-version: stable` in CI resolves to 1.27, and 1.27's `go test` runs the `stdversion` vet check by default. Reproduced locally:

```
unset GOEXPERIMENT; GOTOOLCHAIN=go1.27.1 go test -count=1 -run NONE ./config/
→ 11+ errors: "json.Unmarshal requires go1.27 or later (file is go1.26)"
→ FAIL github.com/LarsArtmann/art-dupl/config [build failed]
```

The gopls warnings AGENTS.md calls "false positives" were never false — Go 1.27 simply didn't exist when that note was written. The AGENTS.md instruction "do NOT bump the go.mod version to 1.27 (Go 1.27 doesn't exist yet)" is now **actively wrong and blocks the fix**.
