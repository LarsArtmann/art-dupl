Architectural reflections

Idiom deletion was the RIGHT call

The idiom category tried to be a "size-based shortcut" for non-actionability, but it conflicted with the group-level actionability evaluator which has access to full AST structure. The 14 AST-based patterns are strictly better: they look at actual code structure (is it a defer? an interface method? a test fixture?) rather than counting tokens. Small clones are now correctly classified by their AST type and assessed by the pattern matcher. This is cleaner, more honest, and produces no contradictions.

printer/ thresholds are policy, correctly placed

The remaining thresholds (functionPriority, typePriority, controlFlowPriority, otherPriority) are classification policy that live in printer/ — not domain. This is correct: domain defines types, printer defines how to present them. No change needed.
