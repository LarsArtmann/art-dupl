04d) Totally Fucked Up

1. The alloc gate shipped with a silent never-fire bug

The first version of check-alloc-regression.sh compared benchmark names without stripping Go's -32 procs suffix — awk never matched, "actual" defaulted to 0, and every budget passed vacuously. Caught while hand-writing the budget file, fixed by stripping the suffix in awk, then proven by fail-injection (101→365 allocs/op → FAIL). Lesson: a gate is not done until you've watched it fail. The T6.3 injection step earned its keep on day one.

2. Misdiagnosed the flake-check failure as "a race with my edits"

First failure → I blamed mid-edit snapshotting and re-ran. Second identical failure → forced the real investigation: untracked files are invisible to Nix flake sources. Two flake runs (~40 min of wall clock) spent confirming something a git status --short | grep '??' against the failing package would have caught in 10 seconds. Compounding factor: the auto-commit daemon usually makes files tracked quickly, so this failure mode stays rare and unfamiliar. Rule going forward: git add new source files BEFORE launching nix flake check.

3. Nearly reported a false "22 groups suppressed" win

While diffing DiscordSync before/after I mixed --plumbing (bypasses suppression) with text mode, which made it look like production code was being wrongly suppressed. Recomputed with matched modes before concluding. Compare like with like.

05e) What We Should Improve

  • Stage new files immediately (git add) — Nix flakes see only tracked files; the daemon's eventual commit is not fast enough to rely on.
  • Diagnose before attributing. "It raced my edits" was a story, not a diagnosis. The second identical failure is the signal to stop re-running and investigate.
  • Launch long checks from green trees only: go build ./... immediately before nix flake check.
  • Never trust a passing gate that hasn't failed — deliberate negative test in the same session for every new gate.
  • One output mode per before/after comparison.
  • Corpus drift is real (go-cqrs-lite moved 2665→2670 across the session; three consecutive runs stable at 2670). Capture before/after minutes apart; re-verify surprises.
