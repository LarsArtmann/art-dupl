1. **Disable or configure the auto-commit daemon for release work.** The daemon's generic commit messages pollute release history. For release sessions, either pause the daemon or ensure ALL edits are staged and committed manually in a single `chore(release)` commit before the daemon picks them up.
2. **Fix AGENTS.md when config changes.** The `makezero` docs drift proves the memory file is not being maintained. AGENTS.md is the AI's memory — if it lies, every future session inherits the lie.
3. **Close the loop on gopls warnings.** Every status report has listed the 7 standing gopls warnings. Neither session has investigated them. Either fix them or document why they're acceptable (e.g., "gopls version mismatch, `GOEXPERIMENT=jsonv2` makes these safe").
4. **Amend old release notes proactively.** When a self-review identifies that a published release has bad notes, fix them immediately with `gh release edit`. Don't leave it as a question for the user.
5. **Test hook resilience.** Verify that `scripts/install-hooks.sh` actually restores the guard after a buildflow hook overwrite. Run `buildflow precommit install`, check the hook is gone, run `install-hooks.sh`, verify it's back.
